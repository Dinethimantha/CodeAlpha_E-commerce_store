 NovaStore - E-commerce Website

NovaStore is a full-stack e-commerce web application that provides a user-friendly online shopping experience. Customers can browse products, search for items, add products to their cart, and place orders online.

The application also includes an admin dashboard for managing products, customers, and orders.

 Features

- User-friendly online shopping interface
- Browse and search products
- Shopping cart functionality
- Online order placement
- Admin dashboard
- Product management
- Order management
- Customer management
- Product image upload

 Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose

 Installation and Setup

1. Clone the repository:

   `bash
   git clone https://github.com/Dinethimantha/CodeAlpha_E-commerce_store.git
   

2. Navigate to the project folder:

   bash
   cd CodeAlpha_E-commerce_store
   

3. Install dependencies:

   bash
   npm install
   

4. Configure your environment variables in a `.env` file.

5. Start the server:

   bash
   npm run dev
   

   Or:

   bash
   node server.js
   

6. Open your browser and visit:

   text
   http://localhost:5000
